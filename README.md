# けやっきーのせかいりょこう迷路！🌍✨ (Labyrinth)

成蹊のマスコットキャラクター「**けやっきー**」が、スクラッチ風の命令ブロックを組み立てて世界各地や宇宙のゴールを目指すプログラミング迷路ゲームです！（全20ステージ）

## 🌐 公開ページ (GitHub Pages)
👉 **https://yuudai20020929-code.github.io/labyrinth/**

---

## 🎮 主な特徴

- **1画面で完結する快適な操作画面**:
  - スクロール不要で、迷路とプログラミングエリア（つかえるブロック、ワークスペース、操作ボタン）が同時に見渡せます。
  - プログラムが長くなった場合も、ワークスペース内部だけがスムーズにスクロールします。

- **マスの中心にピッタリ吸着するけやっきー**:
  - 見下ろし視点（2Dゼルダ風）の迷路ボードで、けやっきーがマスの幾何学的中心に正確に配置されます。
  - 進行方向マーカー（▲）と4方向のイラスト（正面・後ろ姿・左右）で、向いている方向が一目で分かります。

- **スクラッチ風ブロックプログラミング**:
  - ブロックは隙間なくピッタリ連結（スタック）。
  - クリックまたはドラッグ＆ドロップで自由に追加・並べ替え・削除ができます。
  - 「うごかす！」ボタンを押すと、実行中のブロックが黄色くハイライトされ、動作の流れが目で見て分かります。

- **世界旅行＆宇宙大冒険！全20ステージ**:
