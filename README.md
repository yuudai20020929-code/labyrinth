# プログラミングめいろ 🤖 (Labyrinth)

小学生向けのビジュアルブロックプログラミング教材（MVP）です。
「1マスすすむ」「みぎをむく」「ひだりをむく」「くりかえす」などの命令ブロックを組み合わせて、ロボットをお城（ゴール）まで導く迷路ゲームです。

## 🌐 公開ページ (GitHub Pages)
👉 **https://yuudai20020929-code.github.io/labyrinth/**

## 🎮 主な機能・学習要素
- **順次処理（順番に実行）**: ステップごとにロボットが動き、実行中のブロックが光ってわかりやすい！
- **繰り返し（ループ処理）**: 「くりかえす」ブロックの中にブロックを入れて、効率的なプログラムの作成を体験。
- **楽しく学べる演出**:
  - Web Audio API による効果音（ピコピコ音、ぶつかり音、ファンファーレ）
  - ゴール時の紙吹雪演出（Confetti）
  - 本物のプログラミング言語（JavaScript）のコード変換表示機能
- **ステップアップ形式のステージ**:
  - ステージ 1: まっすぐ すすもう！
  - ステージ 2: みぎに まがろう！
  - ステージ 3: ジグザグ みち！
  - ステージ 4: くりかえし で いこう！
  - ステージ 5: スターあつめ だいぼうけん！
