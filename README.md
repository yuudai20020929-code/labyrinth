## 🏫 授業ログイン（Googleスプレッドシート連携）

小学校の授業向けに、**学年・組・出席番号**でログインし、クリア進捗を Google スプレッドシートへ保存できます。教師は専用ページからクラスの進捗確認とテストプレイができます。

### セットアップ手順

1. **新しい Google スプレッドシート**を作成する  
2. メニュー「拡張機能」→「Apps Script」を開き、[`gas/Code.gs`](gas/Code.gs) の内容をすべて貼り付ける  
3. スクリプトをスプレッドシートに紐付けた状態なら `SPREADSHEET_ID` は空のままでOK  
4. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」  
   - 実行するユーザー: **自分**  
   - アクセスできるユーザー: **全員**（匿名ユーザーを含む）  
   - ⚠️ **「組織内のユーザー」だけにすると GitHub Pages から接続できません**（CORS / 401 エラーになります）  
5. 発行された Web アプリ URL を [`config.js`](config.js) の `gasUrl` に貼る  
   - （テスト中は任意）同ファイルの `spreadsheetUrl` にスプレッドシートの URL を貼ると、教師画面から直接 `progress` シートを開けます  

#### トラブルシュート: CORS / 401 エラー

GitHub Pages（`github.io`）から次のようなエラーが出る場合:

- `blocked by CORS policy`
- `401 (Unauthorized)`
- URL が `script.google.com/a/macros/学校ドメイン/...` 形式

**原因:** GAS が「組織内のみ」でデプロイされているため、外部サイトから匿名アクセスできません。ブラウザで学校 Google にログインしていても、GitHub Pages からの fetch には認証は渡りません。

**対処:**

1. Apps Script →「デプロイ」→「新しいデプロイ」  
2. アクセスできるユーザー: **全員** を選ぶ  
3. 新しい `/exec` URL を `config.js` に貼り、GitHub に push  
4. 生徒ログインを再テスト  

#### トラブルシュート: ログインはできるが進捗保存に失敗する

**原因:** Google Apps Script の POST リダイレクトで、ブラウザからの保存リクエストが正しく届かないことがあります。

**対処:**

1. [`gas/Code.gs`](gas/Code.gs) を Apps Script エディタに反映（`doGet` で `saveProgress` を受け付ける版）  
2. **新しいデプロイ**を作成し、`config.js` の URL を更新  
3. ステージをクリアして、スプレッドシート `progress` シートに `cleared` が入るか確認  

（フロント側は生徒のログイン・保存を GET リクエストで送るように変更済みです）

#### トラブルシュート: key が `2003/1/11` のようになり、同じ生徒の行が2重になる

**原因:** 旧形式の key（例 `3-1-11`）をスプレッドシートが日付と誤認し、同一生徒の行を見つけられず毎回新しい行が追加されます。

**対処:**

1. 最新の [`gas/Code.gs`](gas/Code.gs) を反映して **再デプロイ**（key は `G3-C1-N11` 形式になります）  
2. `progress` シートで、同じ `grade` / `className` / `studentNo` の重複行を手動で削除（進捗が入っている行を残す）  
3. 必要なら A列（key）を選択 → 表示形式 → **プレーンテキスト** に変更  

学校方針で「全員」が使えない場合は、GitHub Pages ではなく学校ドメイン内（Google Sites 等）にゲームを置く必要があります。

6. 初回 API 呼び出し時にシート `progress` と `config` が自動作成される  
7. `config` シートで次を変更できる  
   - `teacherPassword` … 教師ログイン用（初期値 `sensei`）  
   - `allowedGrades` … 例 `1,2,3,4,5,6`  
   - `maxStudentNo` … 例 `40`  
   - `maxClass` … 例 `6`

### 使い方

- **生徒**: トップページで学年・組・出席番号を入れて「はじめる」  
- **ゲスト**: 「まずはためす（ほぞんなし）」でシート保存なしのプレイも可能  
- **教師**: `teacher.html` でパスワード入力 → 学年・組を選んで進捗表を表示  
- **テストプレイ**: 教師画面の「ゲームをひらく」→ 進捗はシートに保存されない  

> 注意: 個人名は扱いません。教師パスワードは授業用の簡易認証です。GAS の URL とパスワードは校外に公開しない運用を想定しています。

### 2. 「クリア」と「パーフェクトクリア」判定
従来の3つ星表示を廃止し、より本格的な達成感を得られる2段階クリア判定を導入しました。
- **👑 パーフェクトクリア**：
  - 各ステージの**最短ブロック数**でクリア！
  - 指定ブロックを消さずに残した状態でクリア！
- **✅ ステージクリア**：
  - ゴールに到達！モーダルで「あと〇個減らすとパーフェクトクリアだよ！」と最短ブロック数の目標を教えてくれます。

---

### 3. 「指定ブロック」システム（ステージ11〜19）
ワークスペースに最初から「📌 指定ブロック」が配置されています。
- **条件固定ブロック**：回数や条件の変更ができない仕様（構造を活かして中身を埋める）。
- **条件未固定ブロック**：回数や条件のセレクトボックスを自分で変更できる仕様。
- **注意**：指定ブロックを削除してしまうと、最短手数であっても通常クリア扱いとなります。

---

### 4. 「くりかえす」と「ゴールするまで」の段階的学習（排他配置）
プログラミング初学者が混乱しないよう、1周目（スタンダードコース）では使い分けを徹底しています：
- **ステージ11〜15**：「🔁 くりかえす（for文）」のみ利用可能
- **ステージ16〜20**：「🔄 ゴールするまで（while文）」のみ利用可能

---

### 5. 2周目「🏆 マスターコース」全ブロック解禁！
ステージ20をクリアすると、**「マスターコース」**が解禁されます！
- 指定ブロックの縛りがなくなり、ゼロから自由な発想で構築可能。
- 「くりかえす」と「ゴールするまで」を同時にパレットから選択・併用可能。
- ステージ1から新たな最短記録・別解に挑戦できます。

---

### 6. 4段階のオリジナルメダルコレクション
ゲーム達成度に応じて、画面右上の「🏅 メダル」ボタンからいつでもコレクションを確認できます。
- 🥉 **ブロンズメダル**： スタンダードコース全20ステージをクリア
- 🥈 **シルバーメダル**： スタンダードコース全20ステージをパーフェクトクリア
- 🥇 **ゴールドメダル**： マスターコース全20ステージをクリア
- 🌈 **マスタープラチナメダル**： マスターコース全20ステージをパーフェクトクリア（完全制覇）

### 7. 充実したサポート機能
- **💡 ヒント機能**： 各ステージで「💡 ヒント」ボタンを押すと、クリアのための考え方やアドバイスが確認できます。
- **本物の真偽値センサー**：
  - 「もし」ブロック：条件に合致するかどうかで「カベ〇 / カベ✖」「道〇 / 道✖」とスキャン表示。
  - 「ゴールするまで」ブロック：未ゴール時は「ゴール✖」、到達時は「ゴール〇」と足元をスキャンして判定。
- **💻 JavaScriptコード表示**： 組み立てたブロックが実際のJavaScriptコードでどのように表現されるかをいつでも確認できます。
