# けやっきーの迷路だっしゅつ！🌳 (Labyrinth)

小学生向けのビジュアルブロックプログラミング教材（全20ステージ）です。
成蹊のマスコットキャラクター「**けやっきー**（`images/keyakki.png`）」が、スクラッチ（Scratch）風の命令ブロックを組み合わせて、お城（ゴール）を目指して迷路を脱出します！

## 🌐 公開ページ (GitHub Pages)
👉 **https://yuudai20020929-code.github.io/labyrinth/**

## 🎮 主な特徴
- **Three.jsによる夢中になれる3D箱庭ワールド**:
  - 2Dから立体の3D箱庭迷路へと大進化！
  - カラフルな積み木ブロックの壁、立体メルヘンキャッスル🏰、キラキラ輝く3Dゴールドスター⭐
  - 画面をドラッグすることで**360度自由に見回せるカメラ（OrbitControls）**と「🔄 してんリセット」機能
- **けやっきーの360度立体フィギュア**:
  - 正面・背面・側面（右・左）の全方位テクスチャをAI生成・合成した360度立体フィギュア！
  - 向きを変えるとリアルタイムで旋回し、全方向からけやっきーの姿を楽しめます。
  - 放物線を描くピョーン！と大ジャンプ移動、壁にぶつかった時の「ボヨヨン！」ノックバック、ゴール時の連続宙返り＆3D花火・紙吹雪！
- **広々とした作業スペース（画面の60%以上）**:
  - ブロックの組み立てに集中できる広大なキャンバス。
- **コンパクト＆スクラッチ風密着ブロック**:
  - 上下の隙間なくピッタリ吸着（スタック）し、低学年でもスクロールなしで全体を見渡しやすいコンパクトな設計。
- **ドラッグ＆ドロップ ＋ かんたんクリック追加**:
  - マウスでも指でも、自由な位置にブロックを挿入・並べ替えできます。
- **スモールステップ全20ステージ（段階的ブロック解放）**:
  - ステージ1は「1歩進むだけ」の超カンタン成功体験からスタート！
  - ステージごとに必要なブロックだけがパレットに表示され、段階的に新しい概念を学習。
  - 次のステージに進むと自動でブロックがリセットされ、気持ちを切り替えて新しい問題にチャレンジ可能。
- **プログラミングの4大基本概念を完全網羅**:
  1. **順次処理**: 「1マスすすむ」「みぎをむく」「ひだりをむく」
  2. **繰り返し（Forループ）**: 「🔁 ◯回くりかえす」
  3. **条件分岐（If文）**: 「❓ もし [まえがカベ / まえが道 / いま星がある] なら」
  4. **Whileループ**: 「🔄 [ゴールするまで / まえが道のあいだ] くりかえす」
- **「💻 コードをみる」機能**:
  - 組み立てたブロックが、本物のプログラミング言語（JavaScript）でどう書かれているか確認できます（例: `keyakki.move()`, `while(!keyakki.isAtGoal())` など）。
